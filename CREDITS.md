## Art, models, textures
All 3D models (vehicles, characters, buildings, props, terrain, water, sky), textures and
icons are **procedurally generated by this project's own code** at runtime or build time.
No third-party art assets are shipped. Original work, released with the project.

## Audio
All sound effects, engine sounds, ambience, and the three radio stations (Neon FM,
Dust Radio, Low Tide) are **procedurally synthesised** with the Web Audio API by this
project's own code. No third-party audio assets are shipped.

## Fonts
System font stack only (no web fonts downloaded).

## Adding external assets
Only CC0 / permissive assets (e.g. Kenney, Quaternius, Poly Haven) may be added. Each must be
listed here with: asset name, author, source URL, license, and files using it.
